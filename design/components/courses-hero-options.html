4時間軸接管提案

右欄整個拿掉、時間軸吃滿寬，進行中的 block 加外框光暈＋接上「剩 N 分」。 關鍵理由：同時進行的課一定在不同教室 → 時間軸本來就一間教室一列 → N 堂並行在時間軸上天生就是 N 條線被 now 線穿過，永遠不會長高。 這是唯一「無論幾堂都不會爆」的做法，而且今日課程直接升到第一屏。 代價：進度條、學生名單、快速動作全部沒了；block 只有 30px 高（style.css:1051），一行字就是上限。改動最大。
